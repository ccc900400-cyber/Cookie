Cookie - 多模态智能分析与对话平台

项目简介

Cookie 是一个基于 Google Gemini 3 Flash 模型构建的高性能多模态分析平台。它采用三 Agent 协作架构，提供深度文件解析、视频链接分析、实时会议纪要以及通用的知识问答服务。

核心功能

1. 千析 (Analysis Agent)
- 支持多种格式：PDF、Word、MP4、MOV 等。
- 深度解析：自动提取核心要点，重构逻辑结构，生成结构化 Markdown 报告。
- 链接分析：支持在线视频链接的深度内容提取。
- 报告导出：支持将分析结果一键导出为 Word 文档。

2. 百闻 (QA Agent)
- 智能对话：基于 Gemini 3 Flash 的全场景对话，支持流式响应。
- 实时热点：自动获取并推荐当前 2027 年实时热门话题。
- 知识交互：支持复杂问题的逻辑推理与创意写作。

3. 纪要 (Minutes Agent)
- 实时录音：一键开启会议录音，实时采集音频流。
- 智能转写：自动识别发言人并进行高精度文字转录。
- 结构化纪要：自动生成包含会议主题、核心观点、结论共识及待办事项的专业纪要。
- 历史管理：支持录音回放、纪要导出及历史记录持久化。

技术栈

- 前端框架：React 18
- 构建工具：Vite
- 样式处理：Tailwind CSS (支持响应式布局与暗黑模式)
- 动画库：Motion (react-motion)
- 图标库：Lucide React
- AI 模型：Google Gemini 3 Flash
- 数据持久化：IndexedDB (用于历史记录) & LocalStorage (用于设置)
- 音频处理：Web Audio API

快速开始

1. 环境要求
- Node.js 18 或更高版本
- npm 或 yarn 包管理器

2. 安装依赖
npm install

3. 配置环境
在项目根目录创建 .env 文件并添加您的 Gemini API 密钥：
GEMINI_API_KEY=您的密钥

4. 启动开发服务器
npm run dev

使用指南

1. 进入应用后，左侧导航栏可切换“百闻”、“千析”与“纪要”模块。
2. 在“百闻”模块，您可以直接输入问题或点击下方的实时热点进行对话。
3. 在“千析”模块，您可以拖拽本地文件或粘贴视频链接，点击“开始千析”生成报告。
4. 在“纪要”模块，点击麦克风图标开始录音，会议结束后点击停止即可生成智能纪要。
5. 所有生成的报告与纪要均支持导出为 Word 文档。

技术架构说明

- 模块化 Agent：Agent 逻辑完全解耦，通过统一的 Service 层与 AI 模型交互。
- 响应式设计：采用移动优先原则，针对不同屏幕尺寸优化了字体大小与布局。
- 性能优化：全量采用 Streaming 流式输出，显著提升交互流畅度。
- 隐私保护：数据优先存储于本地 IndexedDB，确保用户隐私安全。
